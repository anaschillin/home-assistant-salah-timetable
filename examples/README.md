# Synthetic CSV example

`annual-example.csv` is a two-day format demonstration with invented sample data,
**not a published mosque timetable**. Do not use it as your prayer-time source.
Upload with year 2026, kind Annual and 24-hour time format to try the mapping/review
workflow in a development Home Assistant instance. The annual coverage warning is
expected because the example contains only two dates.

This example and the input fixtures in `tests/fixtures/csv/` are original synthetic
data provided under the repository's MIT license. CSV oracles extracted from real
PDF publications have separate provenance in `tests/fixtures/pdf/README.md`.
